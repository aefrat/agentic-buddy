Strategic Guide -- Three-Tier Architecture

Tier 1 -- Standalone Builder

  • RHEL + AIB + Language Containers
  • Target: systems admins, cost-sensitive orgs
  • Max control, portable artifacts
  • Entry point creating the OCP "value vacuum"

Tier 2 -- Automotive Suite (RHAS)

  • OCP + Builder Operator + Jumpstarter
  • Pipelines + GitOps + Keycloak
  • Target: Platform Engineers
  • HiL testing via Jumpstarter
  • The core shipped product

Tier 3 -- Unified Environment (IDP)

  • Adds Dev Spaces + Developer Hub + Quay
  • Target: CIO/CISO, greenfield
  • Single vendor, centralized governance
  • Long-term "north star"

Delivery model: IaC (Ansible playbooks), Kubernetes Operators for lifecycle, persona-driven docs. Dual-track release: OS-aligned majors tied to RHIVOS + continuous delivery for Builder/Jumpstarter via feature gates.

Security posture: Software supply chain review (especially Jumpstarter dependencies). Privileged containers mitigated with guidance now, removed architecturally long-term.
