## CY26Q2 Priorities

Here's where the team is focused for this quarter. Some of these will become your primary workstream — we'll align on which ones after you've had a few weeks to ramp up.

### 1. Product vision & PM perspective
Get aligned with the product roadmap and PM vision for 2026. Key context for everything else below — schedule time with the PM early.

### 2. Tech Preview — RHAS work
Active effort to get RHAS to Tech Preview quality. Understand the definition of done, what's blocking, and where you can unblock.

### 3. CTC improvements
Customer/partner-facing toolchain improvements — identify gaps, drive fixes where needed.

### 4. Productization work
Hardening RHAS components for a product-grade release. Involves build, packaging, and release process alignment.

### 5. CIAB (internal)
Internal CIAB (Configuration-in-a-Box or similar) work — internal tooling to support team velocity and integration testing.

### 6. Frontend — UI/CLI
Improving the CLI and any UI-facing surfaces. Usability, consistency, completeness.

### 7. UX — human and AI agent enablement
Designing and building UX that works equally well for a human developer and an AI agent calling the same tools. This is a forward-looking but active investment.

### 8. Shift: from IDE extension to AI-first experience
**The direction is changing.** We're moving away from delivering a VS Code IDE extension directly. The new model: use IDEs as the substrate and build an **AI agent experience on top** — leveraging AI Agents to drive the developer workflow rather than a static extension. This is a key architectural direction you should engage with early.

### 9. Telemetry for services (Flasher, CAIB, etc.)
Monitoring and alerting instrumentation for RHAS services. Needed to operate these services reliably. If you have experience with observability stacks, this is one area where you can have immediate impact.
