# Career aspirations grounding

When responding to a team member's career aspirations, ground the response
in evidence from their recent work rather than generic advice. This makes
the response actionable and credible rather than motivational.

## Pattern

1. Map aspirations to specific progression framework dimensions.
2. Cite concrete examples from the current quarter where the member's
   work already aligns with their stated direction.
3. Identify where the aspiration maps to next-level expectations in the
   framework.
4. Show the gap between current evidence and target level, framed as
   addressable growth areas rather than deficiencies.

## Key insight

The same pattern applies at any level transition. The specifics change
(L4-to-5 focuses on organizational impact; L3-to-4 focuses on scope
expansion) but the method is consistent: aspiration -> framework mapping
-> evidence from recent work -> gap identification -> actionable next
steps.
