# Multi-source framework synthesis

Combining multiple reference documents into a unified assessment
methodology produces richer evaluations than any single source. Each
source provides a different lens, and each lens catches things the
others miss.

## Applied lens stack

1. **IC Progression Matrix** (per job family: SE, SRE, QE) - role-specific
   skill expectations and differentiators at each level.
2. **Job Leveling Framework** (Radford, 3 dimensions: Scope, Complexity,
   Impact) - abstract dimension definitions across the Professional track.
3. **Enterprise Competency Proficiency Levels** (8 competencies x 4
   proficiency tiers) - behavioral readiness table: how someone works,
   not what level of work they do.
4. **Career Track Pathway** (Career Architecture) - structural context:
   career milestone prefixes, job family groupings, pathway options.

## Why each lens matters

- JLF missed Customer Focus gap (Juanje): competency matrix caught it.
- Competency matrix missed Impact dimension gap (Juanje): JLF caught it.
- IC progression matrices provide role-specific differentiators absent
  from the abstract JLF.
- Career pathway context helps frame growth recommendations in terms of
  structural career options, not just skill gaps.

## Evidence

- Development feedback for 10 members across 3 job families using 6
  reference documents (2026-06-29, session 4).
- Talent-development skill execution with 4-lens assessment (2026-06-29,
  session 6): JLF + IC progression + competency proficiency + career
  architecture.
