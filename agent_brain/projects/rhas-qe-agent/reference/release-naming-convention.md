# RHAS Release Naming Convention

## Format

**RHAS-MMYY** where:
- **MM** = Month (01-12, zero-padded)
- **YY** = Year (last 2 digits)

## Examples from CY2026 Roadmap

| Release Name | Expands To | Milestone |
|--------------|------------|-----------|
| RHAS-0226 | February 2026 | Early releases |
| RHAS-0426 | April 2026 | Dev Preview |
| RHAS-0726 | July 2026 | Monthly release |
| RHAS-0826 | August 2026 | Monthly release |
| RHAS-0926 | September 2026 | **Tech Preview** |
| RHAS-1026 | October 2026 | Monthly release |
| RHAS-1126 | November 2026 | Monthly release |
| RHAS-1226 | December 2026 | **GA (General Availability)** |

## Important Notes

1. **This is MONTH-YEAR, not day-month or month-day.**
   - RHAS-1226 = December 2026, NOT December 22 or Nov 26
2. **Zero-padded months:**
   - January = 01, not 1
   - February = 02, not 2
   - etc.
3. **Specific milestones are annotated:**
   - Dev Preview: RHAS-0426 (Dev Preview)
   - Tech Preview: RHAS-0926 (Tech Preview)
   - GA: RHAS-1226 (GA)
