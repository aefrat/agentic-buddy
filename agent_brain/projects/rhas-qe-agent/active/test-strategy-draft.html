2. Scope - RHAS Tier 2 Platform Components

RHAS is a Tier 2 integrated platform targeting platform engineers at automotive OEMs. OpenShift-based with 5 primary components plus supporting services.

Integration Testing Strategy (Aug 17 Decision): Integration testing between automotive dev operator and Jump Starter will use mock devices (QEMU) rather than requiring physical hardware in the test cluster. This simplifies testing while still validating operator interaction with Jump Starter for flashing operations.

3-Layer Test Architecture (Benny Zlotnik):

  • Layer 1: Jumpstarter E2E tests on kind clusters (suitable for Jumpstarter)
  • Layer 2: Builder E2E tests on kind clusters (less ideal - Builder is tailored for OpenShift)
  • Layer 3: Black-box integration testing on real OpenShift (RHAS CI)
    • Phase 1 (OPERATIONAL): Builder + Jumpstarter CI account + ephemeral IPI SNO cluster (one test: build + flash)
    • Phase 2 (PLANNED): Install Jump Starter in the ephemeral cluster (all in one place)
    • Phase 3 (VISION): Run all upstream E2E tests on OpenShift cluster

Downstream Testing Timeline (Aug 17 Decision): Deferred until downstream artifacts (operators, images, Python packages) are available prior to GA. Current upstream testing provides most value.
