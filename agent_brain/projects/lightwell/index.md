# Lightwell

Managed security service by Red Hat. Fixes vulnerabilities in the specific open
source library versions enterprises already run in production - without forcing
upgrades. Launches with Java/Maven, Python/PyPI, and JavaScript/npm.

Source: [Charter Google Doc](https://docs.google.com/document/d/1WAxFFuUZsOf2pNHFhGNjvJBttz49laxg3tvcqOGnhno/edit)
