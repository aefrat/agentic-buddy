# Work Domains

Domains cut across AI involvement categories. A domain may have tasks
in multiple categories. Use these to track which areas of engineering
management work are most and least AI-amenable.

| Domain | Description | Typical category range |
|--------|-------------|----------------------|
| Reporting | Status reports, activity summaries, briefings | Autonomous to Assisted |
| Evaluation | Performance reviews, QC reports, feedback | Assisted to Enhanced |
| Research | Technical investigation, Slack/Confluence research | Enhanced to Assisted |
| Communication | Emails, responses, announcements, updates | Assisted to Human-Only |
| Project tracking | Jira management, backlog review, release tracking | Autonomous to Enhanced |
| Decision making | Priority calls, risk assessment, trade-offs | Enhanced to Human-Only |
| Tool building | Skills, agents, automation, scripts | Assisted |
| People management | 1:1s, development plans, conflict, morale | Human-Only to Enhanced |
| Process design | Workflows, methodology, standards, procedures | Enhanced to Assisted |

## Adding new domains

When a task does not fit any existing domain, add it here with a short
description and typical category range. Update the computed store script
if the new domain needs special handling.
