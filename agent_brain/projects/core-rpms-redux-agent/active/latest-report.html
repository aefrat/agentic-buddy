The 4 Lists

Replacing the single "core RPMs" list with purpose-specific machine-readable JSON lists.

Safety List

Every package touched by file reads or execution. Monitored for CIA & Defect Triage.
Pipeline-generated (boot trace)

Runtime List

Safety List packages still open/mapped after boot. Used during FuSa Triage.
Pipeline-generated (runtime trace)

Image List

Every package in the ASIL portion of the image. Included in validator monitoring.
Pipeline-generated (rpm -qa)

Tools List

Manually curated safety-critical tool packages. Monitored for CIA & Defect Triage.
Curated (downstream only)

Latest generated lists: latest-RHIVOS-2/data-lists/
