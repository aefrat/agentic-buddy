# Career Track Pathway & Job Architecture

Source: Job Architecture - The Source (Red Hat internal, June 2026).

## Job structure

Red Hat's jobs are organized into a hierarchy:

- **Job Family Group** (Job Function) - Broad grouping (e.g., Engineering)
- **Job Family** - Similar areas of expertise (e.g., Software Engineering, Quality Engineering)
- **Job Profile** (Job Title) - Specific job with consistent title globally. In Workday, this is the "Job Profile"
- **Job Code** - Unique number tied to each job title, consistent globally
- **Business Title** - Managers can assign a more personalized title distinct from the Job Profile. The Job Profile determines level and compensation, not the business title

Job Profiles can be used cross-functionally. An engineering Job Profile could exist within both the Engineering organization and the IT organization.

## Career Track Pathway (Career Milestone Prefix)

The Career Milestone Prefix maps comparable levels across tracks. Each prefix groups levels that represent roughly equivalent career stages.

| Prefix | Support | Professional (IC) | Management |
|---|---|---|---|
| E1 | | | Vice President |
| S4 | | | Senior Director |
| S3 | | IC Level 6 (Fellow/Distinguished) | Director |
| S2 | | IC Level 5 (Sr Principal) | Senior Manager |
| S1 | | IC Level 4 (Principal) | Manager |
| C6 | | IC Level 3 (Senior) | Associate Manager |
| C5 | Support Level 5 | IC Level 2 | |
| C4 | Support Level 4 | IC Level 1 | |
| C3 | Support Level 3 | | |
| C2 | Support Level 2 | | |
| C1 | Support Level 1 | | |

**Career Milestone groupings:**
- **C** (Career) - C1 through C6: building foundational and mid-career skills
- **S** (Senior) - S1 through S4: senior individual contributor and senior management levels
- **E** (Executive) - E1+: executive leadership

## Promotions

Promotions include:
1. **Level increases** within a track - any job change that results in an increase in Career Milestone Prefix (e.g., C6 to S1, or S1 to S2)
2. **IC to People Manager transitions** - moving from individual contributor to people manager is a promotion even when the level number decreases (e.g., IC Level 4/Principal to Manager M3)

**Pro tip from The Source:** To broaden skills for the next move, consider trying a different role at the existing job level. The Career Track Pathway shows comparable levels across tracks which can reveal opportunities for lateral growth.

## Job leveling and compensation

The job and job level inform all aspects of compensation:
- Salary grade and range
- Bonus (VIC) target
- Equity eligibility

Global or Regional scope is indicated at the end of the title for Senior Manager and above (e.g., "Senior Manager, Finance_Global"). This designation relates to the scope of the role, not where direct reports are located:
- **Regional:** One or more countries within a region (e.g., France, UK, Ireland, or all of EMEA)
- **Global:** Two or more regions (NA, LATAM, EMEA, APAC)
