# Writing Preferences

Learned patterns from manager feedback on AI-generated report sections. Consolidation only — updated when the manager corrects, rephrases, or comments on a summary.

## How this file is populated

When the manager:
1. Re-runs a report with different phrasing guidance → capture the preference
2. Says "the summary should be more/less X" → capture the directive
3. Edits an AI-generated summary and the edit is observed → diff and capture the pattern

Do not infer preferences from silence. Only capture explicit feedback or observed corrections.

- **Do not include AAA team work in ATC summaries.** The only AAA-related work that should appear is Juanje's individual contributions (he is cross-listed). All other AAA team activity must be excluded from the report entirely.
