## Lessons

- **Use existing tools (jira-cli) instead of raw API calls.** Avi corrected me when I tried to use `curl` against the Jira REST API — the `jira issue view` CLI is already configured and available. Same principle as the manager report: use the tooling that's already set up.
- **Don't re-query when data is already in context.** Avi stopped me from re-fetching all 8 child epics from Jira when the release assignments were already visible from the weekly report HTML and the earlier query. Answer from what you have before reaching for external sources.
- **Slack API `oldest` parameter quirk.** `conversations.history` with `oldest` returned 0 messages even though unfiltered call returned recent messages. Workaround: fetch without `oldest`, filter client-side.
- **Slack MCP was not used in prior sessions** — Avi corrected the assumption. The actual method is direct Slack API calls using `SLACK_XOXC_TOKEN` / `SLACK_XOXD_COOKIE` sourced from crontab, as used in `generate_report.py`.
