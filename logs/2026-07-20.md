## System observations

- **Concept candidate:** "Jira CLI ORDER BY incompatibility" - the `jira` CLI config (`~/.jira/.config.yml`) has a default project that gets appended as `AND project=X` to all JQL queries. This breaks `ORDER BY` clauses because the CLI builds the full query as `<user JQL> AND project=X`, and `ORDER BY` in the middle becomes a parse error. Multiple skill data-sources.md files document queries with `ORDER BY` that don't work. Workaround: remove ORDER BY from JQL and use CLI sorting flags (`--order-by`, `--reverse`). Related to existing observation (2026-06-30): "Jira CLI default project breaks multi-condition JQL." (seen: 2, same root cause as 2026-06-30 observation)
