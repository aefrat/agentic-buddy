- **Google Doc** (ID: `1TeEu6kvDME6nRfZuu1f-VAprWxE8aoMGCGsSuxgQ5Ek`): Initially plain text via `gws docs +write`. Reformatted for presentation quality using Docs API batchUpdate:
  - Proper heading hierarchy (Title, Subtitle, H1, H2)
  - Red-colored section headings, teal subheadings
  - Structured body text covering all 11 pipeline sections

### Lessons

- Google Slides API: object IDs must be at least 5 characters (short IDs like "ns0" are rejected). Outline weight cannot be 0pt (minimum 1pt). Both are undocumented or poorly documented constraints that only surface at runtime.
- Python script approach for building complex slide decks programmatically via the Slides API worked well. Helper functions for common patterns (flow_boxes, make_shape, fill_shape, style_text) made the code manageable despite 200+ API requests across 13 slides.
- Google Docs batchUpdate formatting strategy: (1) delete all content, (2) insert all text as one string, (3) apply paragraph/text styles using tracked ranges. Indices don't shift during styling-only operations, which is much simpler than interleaving insertions and styles.
- `gws docs documents create --json '{"title":"..."}''` for creating new Google Docs (not `--body` flag which doesn't exist).
