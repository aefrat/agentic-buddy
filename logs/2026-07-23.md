## Lessons

- **jira CLI ORDER BY incompatibility:** jira CLI does not support ORDER BY clauses in JQL - consistently returns HTTP 400. Workaround: omit ORDER BY and sort post-query. Encountered in both LP and Core RPMs Redux runs.
- **Slack channel resolution gap:** `team-auto-follow-on-activities` returns empty from slack-mcp `get_channel_id_by_name`. Either renamed, deleted, or bot lacks access. Noted as data source gap for Core RPMs Redux report.
- **gws drive upload vs conversion:** `gws drive +upload` uploads files as-is (raw HTML stays HTML). To convert to a native Google Doc, use `gws drive files create` with `--json '{"mimeType": "application/vnd.google-apps.document"}'` and `--upload-content-type "text/html"`. The `files update` command with the same flags updates an existing converted doc.
