## Lessons
- **Kubernetes IfNotPresent pull policy caches images locally.** When using `:latest` tags, K8s will use a cached local image if one exists with that tag, even if a newer image was pushed to the registry. This caused the CI pipeline to run with an old image missing the openai package. Solutions: (a) use `pull_policy: always` to force registry checks, (b) use SHA or version-based tags instead of :latest, or (c) manually delete cached images. In CI/CD contexts where images change frequently under the same tag, `pull_policy: always` is the right choice despite the registry overhead.
