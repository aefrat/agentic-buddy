## Lessons
- SBI framework works well when the positive intent is acknowledged within the Behavior section rather than as a separate softener - it makes the feedback feel more integrated and less like a "compliment sandwich."
- gws drive files create requires `--upload` flag (not `--media`) for file upload with `--upload-content-type` for MIME type. The `--params` JSON with `mimeType: application/vnd.google-apps.document` does not trigger HTML-to-Docs conversion - files upload as raw HTML. Renaming requires a separate `gws drive files update` call since name in `--params` is ignored during create.
- Gmail send with large HTML attachments can exceed shell argument list limits. For large attachments, either send as separate emails or use Drive links instead of inline attachments.
- Context compaction mid-session requires careful state reconstruction - the session was split across two context windows. Key data (research findings, Jira results, Google Doc exports) had to be carried via the summary since the original tool results were lost.
