## Lessons (session 7)

- **Google Docs renders tables narrower than body text.** Even with `width: 100%`, tables and body paragraphs get different effective widths in Google Docs. The outer container table pattern (wrapping ALL content in a single `<table>`) forces everything into one width context. This is a fundamental Google Docs rendering behavior — not a CSS issue.
- **H2 headings must be standalone for Google Docs consistency.** Headings inside table cells render at the table's width (narrower). Standalone `<h2>` elements render at the body's width. When combined, sections appear at different widths. Solution: never wrap `<h2>` inside `<td>`.

## System observations (session 7)

- **Concept candidate:** "Google Docs outer container table pattern" — wrapping all HTML body content in a single `<table style="width: 100%; border-collapse: collapse; border: none;"><tr><td style="padding: 0;">` forces Google Docs to render tables and paragraphs at the same width. Without this, tables render narrower than body text. Combined with plain H2 headings (not inside table cells), this produces uniform-width Google Docs from HTML. Specific to Google Docs HTML-to-Docs conversion pipeline. (seen: 1)
