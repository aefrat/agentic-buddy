## Lessons

- **Confluence attachment downloads need different auth than API calls.** The v2 pages API works fine with `.netrc` basic auth, but the `/download/attachments/` endpoint returns 401. This is a known Atlassian Cloud quirk — the download endpoint may need cookie-based session auth or a different token scope. For future Confluence work: plan to skip attachments or find an alternative download method.
- **Parallel subagent INGEST is very effective for wiki building.** Running 3 agents in parallel (concepts, workflows, processes) cut the INGEST time roughly in half vs sequential. Each agent had clear boundaries and didn't conflict. The key: give each agent the raw source material inline so it doesn't need to coordinate reads.
- **Avi prefers autonomous execution once a plan is approved.** Multiple interruptions asking to "stop asking questions and complete it all" — clear signal to batch work and only surface blockers, not progress updates or confirmation requests.
