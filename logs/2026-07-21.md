### Lessons
- Google Docs `replaceAllText` batchUpdate requests execute sequentially within a batch. If request 1 changes text that request 5 searches for, request 5 won't match. Encountered this with the release criteria footer - request 1 changed the date, so the footer search (which included the old date) returned 0 matches. Fix: ran a second batchUpdate with the post-replacement text.
- Bold styling in Google Docs requires character-position-based `updateTextStyle` - exported the full doc JSON, found positions of "Gap:" programmatically, then applied bold to each occurrence.
