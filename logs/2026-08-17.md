## Lessons
- AWS Agent Toolkit for AWS (`aws agent-toolkit`) is partially installed by the AWS CLI v2 itself - the subcommands (list-available-skills, get-skill-metadata, etc.) work without explicit toolkit installation. The full setup (`aws configure agent-toolkit`) adds the MCP server config and installs skills to `~/.claude/skills`. Skills are retrieved from a managed AWS service endpoint (us-east-1 only currently). The toolkit always uses us-east-1 regardless of the user's working region.
