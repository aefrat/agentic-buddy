## Lessons
- AWS Agent Toolkit for AWS (`aws agent-toolkit`) is partially installed by the AWS CLI v2 itself - the subcommands (list-available-skills, get-skill-metadata, etc.) work without explicit toolkit installation. The full setup (`aws configure agent-toolkit`) adds the MCP server config and installs skills to `~/.agents/skills/` (Universal), `~/.claude/skills/` (Claude Code), and `~/.cursor/skills/` (Cursor). Skills are retrieved from a managed AWS service endpoint (us-east-1 only currently). The toolkit always uses us-east-1 regardless of the user's working region.
- `aws agent-toolkit add-skill` uses `--skill-name` (not `--name`) as the flag for specifying which skill to install.
- BlendedCost vs UnblendedCost is a critical distinction for AWS Cost Explorer queries in organizations with multiple accounts. BlendedCost averages pricing across the entire AWS org (inflated for accounts that benefit from enterprise discounts). UnblendedCost shows actual charges per account. Always use UnblendedCost for per-account analysis.
- The `aws configure agent-toolkit` command may throw a cosmetic JSON trailing comma error at the end - the resulting config files are valid despite the error message. Don't chase this error.
