## Lessons

- **gws docs API requires `includeTabsContent: true` param** to access Google Doc tab content. Without it, tabbed documents return empty. The tab IDs from the URL fragment (e.g., `tab=t.t4me1ed9nbhc`) map to `tabProperties.tabId` in the API response.
- **gws drive upload does not auto-convert HTML to Google Docs.** Must use `files create` with `mimeType: application/vnd.google-apps.document` and `--upload-content-type text/html` to get server-side conversion.
