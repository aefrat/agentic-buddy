## Lessons
- Red Hat SAML federation to AWS uses `aws login` (browser-based auth from AWS Agent Toolkit), not `aws configure sso`. The SAML URL format (`https://auth.redhat.com/auth/realms/EmployeeIDP/protocol/saml/clients/itaws`) is incompatible with SSO device authorization flow.
- AWS account switching with `aws login` requires explicit `aws logout` first, then re-login and overwrite confirmation when prompted. The profile caches session ARNs and won't auto-switch.
- CloudShell metadata endpoint (`169.254.169.254`) returns 401 - CloudShell doesn't expose instance metadata. Not a viable path for extracting credentials.
- "EC2-Other" in AWS Cost Explorer usually means EBS volumes, snapshots, data transfer, or elastic IPs - not compute. In this case, snapshots alone were $12k/month.

### Lessons
- AWS S3 CloudWatch metrics (BucketSizeBytes) are reported in us-east-1 regardless of bucket region. S3 is a global service with metrics consolidated to us-east-1.
- Velero backup buckets from ROSA/OCP clusters don't appear in CloudWatch S3 metrics by default (returned no data). May need different metric dimensions or direct S3 listing.
- AWS Cost Explorer `describe-snapshots` with `--query 'length(Snapshots)'` returns multiple numbers when pagination occurs - each page prints its own count. Don't sum these blindly.
- Provisioned IOPS (io2) costs appear under "EC2-Other" in Cost Explorer, split into two line items: VolumeP-IOPS (IOPS charge) and VolumeUsage.piops (storage charge). Combined these are the largest cost in the stage account despite being a single storage decision.
- Stage accounts can hold unexpected infrastructure (ROSA cluster, NAT gateways, marketplace subscriptions) that dwarfs the originally assumed partner-bucket-only usage.

## Session 15 - AWS cost analysis continuation (GP3 evaluation)

### Context
- **Continuation of session 13 (AWS cost analysis).** Context compacted after AWS auth expired while attempting to query io2 volume details. Resumed to answer user's question about GP3 vs provisioned IOPS for the ROSA cluster in the stage account.
- **GP3 vs io2/piops analysis completed from existing data.** Back-calculated ~10,660 provisioned IOPS from $693/month IOPS charge ($693 / $0.065 per IOPS). GP3 equivalent cost: ~$214/month vs current $968/month = ~$754/month savings (78% reduction).
- **Evaluation criteria provided:** (1) actual IOPS usage vs provisioned (check CloudWatch), (2) latency requirements (io2 sub-ms vs GP3 slightly higher, fine for staging), (3) durability (99.999% vs 99.8-99.9%, acceptable for staging), (4) ROSA managed service constraints (may require cluster recreation to change volume type).

### Lessons
- Back-calculating provisioned IOPS from Cost Explorer usage-type charges provides a reliable estimate even when direct EC2/EBS API access is unavailable. The formula: monthly IOPS charge / per-IOPS rate = provisioned IOPS count. Combined with volume storage charge / per-GB rate = approximate volume size.
