## Lessons
- Red Hat SAML federation to AWS uses `aws login` (browser-based auth from AWS Agent Toolkit), not `aws configure sso`. The SAML URL format (`https://auth.redhat.com/auth/realms/EmployeeIDP/protocol/saml/clients/itaws`) is incompatible with SSO device authorization flow.
- AWS account switching with `aws login` requires explicit `aws logout` first, then re-login and overwrite confirmation when prompted. The profile caches session ARNs and won't auto-switch.
- CloudShell metadata endpoint (`169.254.169.254`) returns 401 - CloudShell doesn't expose instance metadata. Not a viable path for extracting credentials.
- "EC2-Other" in AWS Cost Explorer usually means EBS volumes, snapshots, data transfer, or elastic IPs - not compute. In this case, snapshots alone were $12k/month.
