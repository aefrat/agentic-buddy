- **Concept candidate:** "Draft build as pre-merge quality gate" - the RoG draft build model inverts the traditional build-then-gate pattern. Instead of building real artifacts and gating them afterward (creating waste on failure), it builds draft artifacts before merge (discarding on failure). This is conceptually similar to feature flags and preview deployments in web development. The pattern generalizes: any "build then validate" pipeline can potentially be restructured as "draft build, validate, then promote." (seen: 1)
